# Calculadora de Estimativa de Horas de Implantação de ERP

Projeto Integrador, disciplina Ciência de Dados Aplicada a Situações de Mercado, Tecnologia em Banco de Dados, Senac EAD.

## Descrição

Este projeto propõe a prova de conceito de um modelo de inteligência de negócio que estima o tempo de implantação de um sistema de gestão empresarial (ERP) a partir de características do cliente, como número de usuários, quantidade de filiais, integrações contratadas e volume de dados.

A estimativa de esforço em projetos de implantação costuma ser feita de forma empírica, sem um critério quantitativo definido, o que aumenta o risco de propostas comerciais subdimensionadas ou superdimensionadas. Este projeto propõe uma abordagem orientada por dados para apoiar esse processo.

Para o desenvolvimento e a validação da prova de conceito, o projeto utiliza como referência o SAP Business One e a metodologia SAP Accelerated Implementation Program (SAP AIP), sistema e metodologia amplamente adotados por pequenas e médias empresas.

## Conteúdo desta 1ª etapa

- Definição da fonte de dados, um dataset fictício de 300 projetos de implantação, estruturado com base em variáveis reais de um documento de handover técnico-comercial;
- Análise exploratória de dados com Pandas e NumPy;
- Cinco visualizações com Matplotlib, com justificativa de como cada uma auxilia a tomada de decisão;
- Distribuição de horas por fase do projeto, seguindo as cinco fases da metodologia SAP AIP (Project Preparation, Business Blueprint, Project Realization, Final Preparation e Go-Live and Support).

## Ferramentas utilizadas

- Google Colab / Jupyter Notebook
- Python
- Pandas e NumPy
- Matplotlib

## Como executar

1. Abra o arquivo `calculadora_implantacao_sap.ipynb` no Google Colab ou em um ambiente Jupyter
2. Execute as células em ordem, de cima para baixo
3. O dataset fictício é gerado automaticamente na primeira célula de código, não é necessário nenhum arquivo externo
